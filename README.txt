# 消防団 お知らせアプリ（登録コードのみ版）

## 構成
- GitHub Pages: `index.html`
- Google Apps Script: `Code.gs`
- Googleスプレッドシート: お知らせ / 端末
- Google Drive: `消防団_お知らせ`

## 1. Googleスプレッドシート
GASをスプレッドシートに紐付けてください。

### お知らせ
初回登録時に自動作成されます。
列：
A 掲載日
B 期日
C タイトル
D 本文
E 重要
F 登録日時
G ファイルID
H ファイル名
I ファイル種類

### 端末
初回登録時に自動作成されます。
列：
A 登録日時
B 端末トークン
C 状態

「状態」を「無効」にすると、その端末はお知らせを読めなくなります。

## 2. Code.gs
以下を必ず変更してください。

ADMIN_PASSWORD = "変更してください";
REGISTRATION_CODE = "変更してください";

登録コードは団員に伝えるコードです。
団員名の入力はありません。

## 3. GASをデプロイ
「デプロイ」→「新しいデプロイ」→「ウェブアプリ」

- 次のユーザーとして実行: 自分
- アクセスできるユーザー: 全員

デプロイ後のウェブアプリURLをコピーします。

## 4. index.html
この行を変更：

const GAS_URL = "ここにGASウェブアプリURLを入れる";

例：
const GAS_URL = "https://script.google.com/macros/s/xxxxxxxx/exec";

その後、index.htmlをGitHub Pagesへアップロード。

## 5. 初回登録
団員が初めて開くと登録画面が出ます。

1. 登録コードを入力
2. 「この端末を登録」
3. GASがランダムな端末トークンを発行
4. ブラウザのlocalStorageに保存
5. 次回以降は登録画面を出さずに利用

団員名は取得・保存しません。

## 6. アクセス制限
お知らせ一覧の取得にも、PDF/画像の取得にも端末トークンが必要です。

Driveのファイルは公開共有しません。
GitHub Pages自体は公開URLですが、データと添付ファイルはGAS側で端末認証を通して返します。

端末を無効化する場合：
「端末」シートの該当トークンの状態を `無効` に変更します。

## 7. 期日間近
期日の3日前から当日まで：
- 最上段へ移動
- 「期日間近」を表示

複数ある場合は、期日が近いものを上に表示。

期日を過ぎると通常の登録日時順に戻ります。

## 8. 添付ファイル
PDF / 画像を登録できます。

Driveには
消防団_お知らせ
  └ 2026-09-20_秋季訓練について
      └ 資料.pdf

のように保存します。

大容量PDFや高解像度画像は、GASのレスポンス容量制限の影響を受ける可能性があります。
